# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- CHANGELOG.md to document project changes.
- Smart search functionality with autocomplete dropdown for table discovery.
- Real-time table filtering as user types in search bar.
- Keyboard navigation support (arrow keys, Enter, Escape) for search suggestions.
- Smooth camera panning and zooming to selected tables.
- Visual highlight animation (pulsing blue glow) for search target tables.
- Enhanced search bar styling with focus states and visual feedback.
- Search dropdown with table names and schema identifiers.
- Interactive search experience with click and keyboard support.

## [1.0.0] - 2026-03-15

### Added
- Initial version of SchemaLens.
- API with endpoints for schema, relationships, and recommendations.
- Web interface to visualize database schema as an ERD.
- Docker-based infrastructure for easy setup.
- Recommendation engine for database schema improvements.
